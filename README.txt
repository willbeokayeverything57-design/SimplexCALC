SIMPLEX METHODS WEBSITE

Files:
- index.html: page structure
- style.css: design and responsive layout
- script.js: mobile menu, simplex calculator, and demo feedback form
- assets/teacher.jpg: teacher photo supplied by the team
- materials/: available PDF/PPT learning materials

How to run:
1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.

Calculator:
Supports maximization problems of the form:
Maximize Z = c1*x1 + c2*x2 + ...
Subject to constraints A*x <= b and x >= 0, where b >= 0.
Enter objective coefficients separated by commas.
Enter one constraint per line, e.g. 2, 1 <= 8
This is a classroom demo, not a complete solver for every LP form.
